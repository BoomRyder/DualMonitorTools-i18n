Dual Monitor Tools は Gerald Evans による Windows のマルチモニター向けツール集です。このリポジトリは 2.13 の多言語版です。表示言語は簡体字中国語、繁体字中国語、日本語、韓国語、英語から選べます。最初の起動は簡体字中国語です。

上流プロジェクト: <http://dualmonitortool.sourceforge.net>

## 機能

- 🖱️ **カーソル** — ポインターを 1 台のモニターに固定する、または隣の画面へ移るのにひと手間かかる吸着にする
- 🚀 **ランチャー** — 短いマジックワードでプログラム、文書、Web ページを開き、ウィンドウを決めた位置に置く
- 📸 **スナップ** — プライマリ モニターの画面を別の画面に表示し、後から見る、保存する、コピーする
- ↔️ **画面の入れ替え** — ウィンドウをモニター間で動かし、半分、四分の一、保存した領域へスナップする
- 🖼️ **壁紙チェンジャー** — 複数のソースから壁紙を切り替え、1 枚の画像を複数モニターにどう広げるかを決める
- 🧩 **DualWallpaper** — マルチモニター用の壁紙を手作業で作る
- 💤 **DmtWallpaper** — DMT が最後に作った壁紙を表示するスクリーン セーバー
- 🌐 **5 つの表示言語** — 簡体字中国語、繁体字中国語、日本語、韓国語、英語。*オプション → Dual Monitor Tools → 全般 → 言語* で切り替え、選択は保存される

## はじめに

| 形態 | 実行するもの | 説明 |
| --- | --- | --- |
| **セットアップ** | `installer\DualMonitorTools.msi` | 管理者権限が必要。データは `%APPDATA%\Dual Monitor Tools` |
| **ポータブル** | 任意のフォルダーの `DMT.exe` | データは exe の横。`DmtFileLocations.xml` は同梱しない |
| **ソースから** | `.\build.ps1` のあと `installer\Build.bat` | [ビルド](#ビルド) を参照 |

インストーラーは上流の WiX MSI です。`installed=1` を書き、スクリーン セーバーは 32 ビットのシステム フォルダーへ入ります（64 ビット Windows では `SysWOW64`）。空のデスクトップ右クリック項目も残ります。言語のサテライト アセンブリは含まれません。dll を別に置かないと表示は英語に戻ります。

「更新の確認」は、上流版を開くかインストールする前に確認します。既定は「いいえ」です。「はい」を選ぶと、このビルドは上流の英語版に置き換わります。

## ビルド

Visual Studio 2019 または 2022 の .NET デスクトップ開発ワークロード（.NET Framework 4.0 Client Profile と 4.5）、および MSI 用の WiX Toolset 3.14 が必要です。

```powershell
.\build.ps1
.\build.ps1 -Configuration Release -Test
cd installer
.\Build.bat
```

言語サテライトは各プログラムの横の `zh-Hans`、`zh-Hant`、`ja`、`ko` フォルダーに出力されます。
